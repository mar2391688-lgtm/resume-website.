## Project Overview

This project is a one-page online resume created using HTML5 and CSS3. The purpose of this website is to showcase my education, technical skills, experience, and projects while demonstrating my knowledge of web development and accessible website design.

The resume focuses on my interests in web development, IT support, and Linux system administration.

## Technologies Used

- **HTML5** – Semantic webpage structure
- **CSS3** – Website styling and responsive layouts
- **Git and GitHub** – Version control
- **GitHub Pages** – Website hosting

## Website Features

- Professional resume layout
- Responsive design for desktop and mobile devices
- Accessible navigation and semantic HTML
- Professional overview and career objective
- Technical skills and relevant coursework
- Experience and education sections
- Volunteer and community involvement
- Projects and achievements
- Dark green color scheme

## Validation and Accessibility

The website was designed using semantic HTML5 and responsive CSS3.

Accessibility features include:

- Descriptive navigation labels
- Proper heading structure
- Keyboard focus indicators
- Mobile-friendly layouts
- Reduced-motion support

HTML and CSS validation can be performed using the W3C validation tools.
